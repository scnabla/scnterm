# 上游同步与独立配置程序开发计划

## 目标与范围

同步 WezTerm 上游更新，验证后发布新版 ScnTerm；随后开发独立 Windows 配置程序。配置程序保存在 `personal-config` 仓库的 `tools/scnterm-config/` 目录，独立管理源码、依赖、测试、构建和发布。只允许编辑串口连接、日志和高亮配置，其他配置只读。具体文件保护要求见 [TODO-003](todo.md#todo-003-独立-lua-配置程序)。

## 执行步骤

1. 建立更新分支，合并上游 `e1eae81a5`，核对文本冲突及窗口标题、焦点通知、Windows 临时文件改动。
2. 执行相关模块测试及 Linux、Windows 构建，回归串口日志与高亮、SSH 目录菜单、默认 Shell、分屏和关闭确认。
3. 验证通过后合入 `personal`，更新跟随上游的 `main`，触发按平台发布，核对新包版本并交付 Windows 成果物。
4. 建立独立配置程序，实现不执行 Lua 的解析、保留原文的局部编辑、差异预览、语法与字段检查、备份恢复及外部修改检测。
5. 实现 Windows 独立窗口，提供串口连接、日志和高亮规则编辑；SSH、快捷键、主配置和无法识别的动态代码只读。
6. 使用配置副本验证增删改、错误输入、动态代码保护、重复保存、外部修改和备份恢复；完成 Windows 打包与独立桌面验证。
7. 更新使用和开发文档、配置示例与待办，推送独立项目源码及发布包，核对线上文件与交付版本。

## 验证与交付约束

- 不修改用户日常配置进行测试，不关闭用户正在使用的终端或串口连接。
- GUI 测试在独立测试桌面进行，不切换当前桌面或抢占键盘鼠标。
- 测试日志和构建产物与源码分开保存，提交仅包含相关源码、文档及公开示例。
- 编译、自动测试、界面操作和实机通信分别记录；合并与发布以实际通过的检查为依据。
